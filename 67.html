How to create quizzes with Python

You can easily generate quiz files in Python! Paste this simple script into any Python editor to create your custom, organized JSON quiz file: 

import json

# Your custom organized questions list
quiz_questions = [
    {
        "question": "Which programming language is known for its simplicity and readability?",
        "options": ["Java", "Python", "C++", "Assembly"],
        "correct_index": 1,
        "explanation": "Python is designed to be highly readable with simple syntax resembling English."
    },
    {
        "question": "In Python, which keyword is used to start writing a function?",
        "options": ["function", "def", "func", "define"],
        "correct_index": 1,
        "explanation": "The 'def' keyword is used to declare user-defined functions in Python."
    },
    {
        "question": "What extension is used for standard Python code files?",
        "options": [".py", ".json", ".txt", ".html"],
        "correct_index": 0,
        "explanation": "Python files always end with the '.py' file extension."
    },
    {
        "question": "Which data format uses curly brackets {} and looks like Python dictionaries?",
        "options": ["CSV", "HTML", "JSON", "XML"],
        "correct_index": 2,
        "explanation": "JSON (JavaScript Object Notation) utilizes key-value pairs formatted with curly brackets."
    },
    {
        "question": "What is the correct index for the FIRST element in a list/array in Python?",
        "options": ["1", "-1", "0", "First"],
        "correct_index": 2,
        "explanation": "Python lists are zero-indexed, meaning the first item is located at index 0."
    }
]

# Save to organized JSON file
with open("my_python_quiz.json", "w") as file:
    json.dump(quiz_questions, file, indent=4)

print("Quiz file 'my_python_quiz.json' successfully generated!")
